# 模块文档：apps/web

## 职责

统一前端，承载博客与 OJ 两套业务视图，保证：
1. 统一主题风格与交互动效
2. 统一登录态体验（博客/OJ联动）
3. 网关模式下统一 API 前缀

## 目录建议

1. `app/`：页面与路由
2. `components/`：可复用组件（导航、通知、列表、编辑器等）
3. `lib/`：接口调用封装、会话桥接、视图过渡
4. `types/`：类型声明

## 路由逻辑

1. 博客主站：首页、写作台、个人页、搜索、排行榜  
2. OJ 区域：题目列表、题目详情、提交记录、排行  
3. 网关转发：
   - 博客 API：`/blog-api`
   - OJ API：`/blog-api/api/v1/oj`

## 关键交互要求（现行基线）

1. 页面切换避免全量刷新与闪屏。  
2. 提交通知采用统一顶部通知样式。  
3. 题目页重点区（题面/编辑器/底边栏）布局稳定，不抖动。  
4. 支持暗黑模式并优先跟随系统。  

## 与后端契约

1. 博客接口：`/api/v1/*`（经网关映射到 `/blog-api/*`）  
2. OJ 接口：`/api/v1/oj/*`（经网关映射到 `/blog-api/api/v1/oj/*`）  
3. 登录态：前端统一使用后端 Cookie + Redis Session，避免模块各自维护。
